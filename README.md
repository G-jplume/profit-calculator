# 跨境电商新品利润核算工具

基于原始 Excel 利润核算表构建的 Streamlit Web 应用，支持跨境电商新品定价决策。

## 功能特性

### 三大业务线
- **AMZ FBM** (亚马逊自发): 6大海外仓自动比价，淡旺季双期利润对比
- **AMZ FBA** (亚马逊代发): FBA尺寸分段自动判定，AGL散货/整柜头程计算
- **Walmart WF** (出仓价核价): 22%扣点反推出仓价，加价率1.7-2.1x前台售价

### 核心计算
- **成本构成**: 商品成本 + 头程 + 尾程物流 + 佣金 + 广告 + 退货 + 仓储
- **6仓比价**: 良仓、大方广、诺一奥、无忧达、派速捷、优派
- **FedEx费率**: 基础运费(35%折扣) + 附加费 + 旺季附加费
- **多产地**: 中国(人民币÷汇率) / 越南泰国(÷1.1含退税) / 马来西亚

### 费率参数
| 项目 | AMZ FBM | AMZ FBA | WF |
|------|---------|---------|-----|
| 佣金 | ≤$200:15% / >$200:10% | 同左 | 22%扣点 |
| 广告 | 8% | 10% | — |
| 退货 | 3% | 3.5% | — |
| 仓储 | 1% | 1.5% | — |

## 快速开始

```bash
pip install -r requirements.txt
streamlit run app.py
```

## 使用方式

1. 在左侧边栏填写产品信息（品名、产地、售价、采购成本、包装尺寸等）
2. 选择业务类型（AMZ FBM / AMZ FBA / Walmart WF）
3. 查看自动计算的成本明细、利润情况、6仓比价结果
4. 通过图表分析成本结构和各仓物流费对比

## 数据来源

- FedEx 基础运费: 2024.1.1 起，35%折扣结算价
- 附加费: 2026年1月更新
- 旺季附加费: 2024.9.30-2025.1.19 时间段
- CG仓费率: 7个分类（Bin Small → Standard Oversize）
